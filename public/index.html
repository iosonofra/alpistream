⚡ Proxy AceStream Centralizzato (Zero Engine sui Client)

Se abilitato, tutti i canali AceStream nella lista M3U e nel Web Player verranno riprodotti come normali flussi HTTP tramite il server MandraKodi, senza richiedere Ace Engine sui dispositivi client (Smart TV, Kodi, VLC, smartphone).
Specificare 127.0.0.1:6878 per engine locale o container Docker/LXC sulla stessa macchina, oppure IP_SERVER:6878 per engine su un host remoto.

🔐 Proxy MPD ClearKey Centralizzato (FFmpeg Stream Copy)

Se abilitato, tutti i canali protetti da ClearKey DRM (oltre 250 canali Sky, Sport, Cinema) verranno decifrati al volo dal server in streaming continuo MPEG-TS senza transcodifica (stream copy a zero carico CPU), rendendoli riproducibili su qualsiasi Smart TV (Samsung/LG), VLC o TV box senza bisogno di moduli DRM.

🛡️ Proxy Cloudflare WARP SOCKS5 (Bypass Blocchi & CDN Protette)

Se abilitato, instrada selettivamente i canali contrassegnati e i gruppi selezionati attraverso il demone Cloudflare WARP locale, aggirando blocchi CDN e georestrizioni senza toccare la rete locale o AceStream.
Predefinito per il servizio Alpine LXC: 127.0.0.1:40000. Puoi avviare il servizio sul container eseguendo: ./alpine/setup-warp.sh.
Opzionale. Se possiedi un abbonamento Cloudflare WARP+, inserisci qui la tua chiave di licenza a 26 caratteri.
Seleziona i gruppi (es. SPORT - HTSport) che devono passare automaticamente attraverso il proxy Cloudflare WARP.
